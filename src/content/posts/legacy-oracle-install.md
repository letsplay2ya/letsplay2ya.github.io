## 오라클 설치

-   오라클 19c를 설치 (공식 홈페이지: [https://www.oracle.com/database/technologies/oracle-database-software-downloads.html#19c](https://www.oracle.com/database/technologies/oracle-database-software-downloads.html#19c))
    
-   아래 화면에서 zip 파일을 다운로드  
    ![오라클 설치 파일 다운로드 화면](/legacy-assets/images/install_01.png)
    
-   압축을 해제 후, sepup.exe을 실행하여 오라클을 설치
    
-   C드라이브 내 ORACLE 폴더를 만들어 그 안에 설치 파일을 넣음
    
-   비밀번호 작성 후, 컨테이너 데이터베이스 생성 박스는 체크를 해제
