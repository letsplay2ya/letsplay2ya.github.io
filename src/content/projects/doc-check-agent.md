README에서 안내하는 파일과 실행 명령이 실제 예제와 맞는지 확인하는 작은 도구입니다. 업무 프로젝트나 상용 Agent 서비스가 아닌 **개인 실험**입니다. 실제 모델 호출 전에도 도구 경계·종료 조건·근거 검증을 평가할 수 있도록 구성했습니다.

## 구현한 것

파일 목록, 파일 읽기, 문서의 불일치 후보 검사, 근거가 확인되는 보고를 도구로 분리했습니다. 호스트는 호출 예산과 읽기 경로를 제한하며 후보의 위치가 확인되지 않는 보고는 거절합니다. LLM이 생성한 명령을 셸에서 실행하지 않습니다.

## 실행한 결과

규칙 기반 고정 순서 검사는 6개 샘플 중 5개에서 전체 기대 결과와 일치했습니다. 참양성 2건, 거짓양성 1건으로 정밀도는 약 66.7%입니다. 오탐은 실행 지시가 아닌 설명용 명령을 구분하지 못한 사례입니다. 표본이 작은 인공 데이터이며 모델 성능 지표가 아닙니다.

## 모델 연결 범위

OpenAI Responses API 어댑터와 함수 호출 결과를 전달하는 루프를 구현했습니다. 실제 API 키가 없어 모의 응답으로 계약만 검증했고, 모델 품질·비용·네트워크 지연은 측정하지 않았습니다. 브라우저에서는 기준 검사의 저장된 실행 기록만 보여줍니다.

## 직접 재현하기

[예제 폴더](https://github.com/letsplay2ya/letsplay2ya.github.io/tree/master/public/examples/doc-agent)를 받고 baseline·평가·테스트를 실행할 수 있습니다. [실험실](/lab/)에서 오탐 사례와 도구 호출 결과를 확인할 수 있고, [구현 글](/writing/notes-doc-agent/)에 평가 기준과 한계를 설명했습니다.
